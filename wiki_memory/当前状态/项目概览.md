# 项目概览

归录是用户要求的 Windows 班级课堂考勤应用，面向每天登记异常考勤及学期末汇总。

已明确使用 React + Vite + Tauri，交付网页开发服务器、Windows EXE、最新版压缩包和解压目录。界面参考 Notion 官方 UI 和提供的移动课表截图，按桌面布局实现。

本轮实现与检查结果见 [[日志/2026-09-20-班级考勤初版]]，未经过用户验收的具体技术选型保留为候选记忆。
