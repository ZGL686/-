# 系统架构

本页为 0.3.0 实现快照，等待用户验收后确认长期架构。事实来源为代码和本轮检查，不等同于已确认选型。

| 模块 | 入口 | 职责 |
| --- | --- | --- |
| 应用外壳 | src/App.tsx、src/app/ | 导航元信息、顶栏、侧栏、唯一班级入口 |
| 公共 UI | src/components/ui/ | 按钮、图标提示、菜单、弹窗、抽屉、通知、标题、错误恢复 |
| 设备偏好 | src/preferences/ | 字体、字号、动效、侧栏状态；结构校验与独立 localStorage |
| 设置特性 | src/features/settings/ | 学期、外观、备份、名单导入与新工作台 |
| 业务 | src/model.ts | 数据约束、北京时区、教学周、统计 |
| 数据库界面 | src/features/database/ | 页面协调、查询模型、操作、表格 / 卡片 / 布局、属性与视图配置、详情 |
| 考勤编辑 | src/features/attendance/RecordEditor.tsx | 登记与数据库共用的完整考勤编辑器 |
| 数据库逻辑 | src/database-schema.ts、database-engine.ts | 自定义属性、保存视图、筛选排序、分组、列计算、学生关联汇总 |
| 文件 | src/files.ts | 名单导入、Excel/Markdown/JSON |
| 保存 | src/context.tsx、src/storage.ts | 保存成功后更新界面、版本冲突检查 |
| 桌面 | src-tauri/src/lib.rs | SQLite WAL/FULL 事务、完整快照 |
| 浏览器 | IndexedDB | 独立预览数据，可通过 JSON 迁移 |

每个工作台独立保存学生、课程、考勤、学期设置。考勤保留课程快照，课表调整不重写历史。

数据 schema 继续为 2，每个工作台包含学生 / 考勤两个数据库的属性、单元格及视图。旧 schema 1 在内存中补全，首次成功保存才写入新版；SQLite 原始快照保留。更名为 Ludian 不更改应用标识 cn.guilu.attendance、用户数据目录及备份格式。完整备份包含业务字段，不包含设备外观偏好。

灰白主题、蓝色操作按钮，离线圆体 / 文楷 / Noto Sans SC 与系统字体可选；默认圆体。字体完整字符映射、OFL 许可、固定来源与哈希在 public/fonts/，不依赖学生名单生成子集。样式分层在 src/styles/。

公共 UI 不导入业务或偏好；纯业务逻辑不导入界面。npm run check 检查 Hooks、类型 / 格式、依赖环、模块边界和单文件规模。交互、测试隔离及模块约定见 docs/架构与交互规范.md。
