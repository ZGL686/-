# 系统架构

本页为 0.2.0 实现快照，等待用户验收后确认长期架构。事实来源为代码和本轮检查，不等同于已确认选型。

| 模块 | 入口 | 职责 |
| --- | --- | --- |
| 界面 | src/App.tsx 及页面组件 | 工作台、课表、登记、汇总、设置 |
| 业务 | src/model.ts | 数据约束、北京时区、教学周、统计 |
| 数据库界面 | src/Database.tsx、DatabaseMenus.tsx、DatabaseDetail.tsx | 五种视图、行内/侧面编辑、属性与视图设置 |
| 数据库逻辑 | src/database-schema.ts、database-engine.ts | 自定义属性、保存视图、筛选排序、分组、列计算、学生关联汇总 |
| 文件 | src/files.ts | 名单导入、Excel/Markdown/JSON |
| 保存 | src/context.tsx、src/storage.ts | 保存成功后更新界面、版本冲突检查 |
| 桌面 | src-tauri/src/lib.rs | SQLite WAL/FULL 事务、完整快照 |
| 浏览器 | IndexedDB | 独立预览数据，可通过 JSON 迁移 |

每个工作台独立保存学生、课程、考勤、学期设置。考勤保留课程快照，课表调整不重写历史。

0.2.0 的数据 schema 为 2，每个工作台包含学生 / 考勤两个数据库的属性、单元格及视图。旧 schema 1 在内存中补全，首次成功保存才写入新版；SQLite 原始快照保留。升级不更改应用标识或用户数据目录。完整备份包含新字段。

灰白主题、蓝色操作按钮、离线 Noto Sans SC 字体；字体完整字符映射与 OFL 许可在 public/fonts/，不依赖学生名单生成子集。界面细节和数据库功能范围见 docs/设计参考.md。
