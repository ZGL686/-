# 2026-09-20｜Ludian 交互与模块化改造

- 类型：feature
- 状态：完成 0.3.0 实现、回归与解压版验证
- 目标：修复点击收起侧栏后的白屏，简化左上角，提供不同字体和交互反馈，从公共模块及质量检查维护整体可维护性。
- 日志索引：[[日志/MOC_工作日志]]

## 用户明确的要求

产品改名 Ludian、采用黑白 Notion 风格图标；选择单一班级入口，字体风格应差异明显，交互反馈清晰但克制。避免各处孤立实现、重复代码和不断堆积的页面。保留既有数据、发布、备份、提交推送与工程记忆约束。

## 原因与实现

- 旧 CSS Grid 将侧栏隐藏后主内容自动排入零宽列；主区域在 1440px 窗口实测由 1208px 变为 0px，没有 JS 异常。改为显式 sidebar / main 区域，收展入口始终在顶栏，折叠侧栏不再可聚焦。
- 拆出 AppShell、WorkspaceSwitcher 和统一导航元信息；左上角只有班级 / 学期 / L 图标，下方重复工作台列表移除。
- 新增公共 Button、IconButton、TooltipProvider、Popover、Modal、Drawer、Toast、PageHeading、ErrorBoundary，统一鼠标、键盘、焦点、提示、过渡、待保存与失败反馈；提示支持原生 dialog 顶层，点击弹窗内容留白不会关闭。
- 数据库拆成页面协调、模型、操作、表格、卡片、布局、属性和配置模块；设置拆成学期、备份、新建与外观；考勤编辑器共用。删除旧大型组件。样式按变量 / 基础 / 外壳 / 特性 / 浮层 / 交互等职责分文件。
- 四字体和三档字号，支持减少动效与恢复默认。圆体和文楷来自固定版本官方开源字库，转换完整 WOFF2 并改衍生字体名称，保留版权许可及哈希；原黑体保留，不按名单裁字。
- 偏好经校验写入独立 localStorage 键；错误字段回退，存储失败提示仅会话有效，不影响考勤。页面级和根级错误边界提供恢复入口。
- 保存错误状态与通知解耦，失败后顶栏持续提示；仅持久化成功显示已保存。原事务、乐观版本检查和业务数据 schema 保留。
- 版本 0.3.0，Ludian.exe 与黑白 L 图标；保留原应用标识、SQLite / IndexedDB、备份格式及旧版数据目录。
- 增加 ESLint、架构依赖环 / 边界 / 文件规模检查、格式与类型检查命令。未改变生产依赖版本。

## 文件变更

主要入口：src/app/、src/components/ui/、src/features/database/、src/features/settings/、src/features/attendance/、src/preferences/、src/styles/。更新 App、业务页面、context、图标 / 字体、桌面版本、打包与隔离验收脚本、测试、README、使用说明、架构规范及验收记录。

## 验证结果

- npm run check 通过：50 个模块无依赖环、层边界和文件规模检查通过，ESLint 零警告、格式与 TypeScript 通过。
- 30 项单元、17 组浏览器 E2E、3 项 Rust 单元全部通过；完整 release 构建完成。
- 新增回归覆盖六页面三宽度收展、往返菜单 / 弹窗 / 抽屉、键盘焦点、四字体 / 字号、减少动效、偏好损坏 / 写入失败与页面错误恢复；原数据库和备份等用例保留。
- 独立桌面环境使用两名虚构学生的旧快照，升级后两条考勤和四个快照；原记录及原始 payload 保留。属性、画廊视图、侧栏与外观偏好退出重启后保留，原生保存 JSON 通过，三款内置字体实际加载。
- 测试中发现旧 QA 的绝对 dataDirectory 被 Tauri 忽略，外观缓存共用默认目录；考勤始终隔离。改为 WEBVIEW2_USER_DATA_FOLDER，并在操作前校验实际子进程目录，重跑通过；仅清理了与测试值完全匹配的新增偏好键，未清空其他缓存或真实数据库。
- 1100×760、1440×1000、2048×1152 / DPR 1.25 人工与自动视觉检查通过；四字体下主要页面无页面级溢出或 JS 异常。真实物理屏幕感受仍待用户确认。
- 最终 Ludian.exe 在另一个 SQLite / WebView 双独立目录中用虚构旧数据启动、正常退出，原 payload 保留，无调试端口。
- ZIP 全部四文件与解压版逐字节一致；Windows 产品名、文件描述及版本已核对。详情见 docs/验收记录-0.3.0.md。
