# 2026-09-20｜Notion 界面与数据库改造

- 类型：feature
- 状态：完成 0.2.0 实现、桌面升级与发行验证
- 目标：根据用户反馈，进一步查看 Notion 官方 UI 图片和数据库手册，重做色调、布局与数据库交互，改善字体观感。
- 日志索引：[[日志/MOC_工作日志]]

## 用户明确的要求

初版绿色主题与 Notion 不符，需要更多官方图片依据；深度研究官方数据库文档，进一步模仿数据库功能；整体布局继续调整，排查文字锯齿。沿用既有本地保存、跨版本保护、压缩包与解压版、提交推送要求；开学日期仍可随时修改。

## 研究与实现

- 实际打开、查看三张 Notion 官方原图，阅读视图、筛选、排序、属性、表格、看板、画廊、日历、关联汇总和设置手册。图片来源与功能对应在 docs/设计参考.md。
- 重做全局灰白色调、蓝色操作按钮、紧凑侧栏与顶部导航、全宽数据库和课表；移除绿色品牌装饰，放大过小的辅助文字。
- 学生 / 考勤两个数据库共享底层业务记录，提供表格、看板、画廊、列表、日历；保存视图、新建 / 复制 / 删除视图、AND/OR 筛选、多级排序、分组和当前视图 CSV。
- 提供文本、数字、单选、多选、日期、复选框属性，表格行内编辑、批量编辑、列顺序 / 宽度 / 可见性、列计算、看板拖动改组、右侧详情。考勤关联学生，统计随有效记录变化，保留原 +1 工作流。
- 引入 schema 2，旧数据内存兼容、首次成功写入升级；原始 SQLite 快照保留。新视图和属性进入完整备份，继续通过原事务和版本冲突边界保存。
- 调查确认原字体为 Microsoft YaHei UI，系统已开启 ClearType；未更改系统设置。内置官方 Noto Sans SC 完整字符映射 WOFF2，保留 OFL 许可；浏览器和桌面平台字体接口确认实际加载。
- 版本升至 0.2.0，个人发行包包含字体许可证。真实名单和个人发行物保持本机忽略，不进入 Git；自动化使用虚构学生。

## 验证结果

- TypeScript / Vite 生产构建通过；21 项单元、10 组浏览器 E2E、3 项 Rust 测试通过。
- 桌面隔离验收从虚构 v1 快照升级：1 条旧记录保留，新增后共 2 条；新属性、当前视图重启后保留。4 个快照，原始 v1 payload 完全未变。
- Windows 原生保存对话框导出 JSON 并读回通过。
- 1100×760、1440×1000、2048×1152 / 125% 视口检查无页面级横向溢出及 JS 错误；人工查看表格、详情、筛选、画廊、课表、登记、汇总和设置截图。
- 最终发行 EXE 在另一隔离目录启动、退出通过，初始化 64 人、0 条考勤、schema 2，无调试端口；没有测试记录混入个人包。
- ZIP 内全部 4 个文件与解压版逐字节一致。详细检查在 docs/验收记录-0.2.0.md。
