# 2026-09-24｜工作台管理、主题与考勤撤销

- 类型：feature
- 状态：完成 0.4.0 实现、检查和发行目录验收。
- 目标：工作台可编辑与删除；主题支持跟随系统 / 浅色 / 深色；考勤登记具备加号与撤销减号，保持公共模块和数据兼容。
- 日志索引：[[日志/MOC_工作日志]]。

## 用户明确需求与实现

用户要求上述三项整改，并继续按照日常使用习惯优化。工作台管理入口放在唯一班级菜单，支持名称 / 学期编辑、空工作台创建、删除确认、回收站与恢复；当前工作台删除后原子切换，最后一个使用中工作台受保护。

外观按用户参考图增加三张主题卡；语义颜色变量覆盖页面、表格、菜单、弹窗、抽屉和标签；主题独立保存，监听系统变化并同步 Tauri 标题栏。字体与主题共用 ChoiceCards 的单选语义和方向键交互。

各学生考勤类型增加减号，打开按同学 / 类型筛选的明细，当前日期课程优先，选择具体记录撤销。历史记录可恢复；最近批量或补记支持撤销与恢复。撤销逻辑共用且保留课程快照、备注和自定义属性。

## 代码与保存

- `src/features/workspaces/`：工作台生命周期模型与管理窗口。
- `src/features/attendance/`：拆出的课程表单、个人明细与共享撤销模型。
- `src/components/ui/`：共享选择卡片、通知顶层容器；保存冲突时通知不被模态弹窗遮挡。
- `src/preferences/` 与 `src/styles/`：主题偏好、全局颜色变量和固定预览样本。
- 学期表单只保存修改字段，管理窗口编辑后同步未修改字段，保留本地日期草稿。
- Schema 3 兼容旧版 1 / 2，仅成功保存写入新版，原快照不变；原应用和存储标识不变。备份包含回收站；旧程序拒绝新版结构，防止新字段丢失。
