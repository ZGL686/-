# 2026-09-20｜班级考勤初版

- 时间：2026-09-20 21:13（北京时间）
- 类型：feature
- 状态：完成本地实现与交付验证
- 目标：依据用户需求、课表、四张截图和班级学生表构建初版 Windows 考勤应用。
- 日志索引：[[日志/MOC_工作日志]]

## 已确认的需求

React + Vite + Tauri；网页开发与 EXE；dist/ 的最新版压缩包和解压版；数据跨版本保留及完整备份；新名单新工作台；每次完整修改提交推送。用户补充确认开学日期支持随时更改。

## 检查与实现

- 只读核对需求、课表、四张参考截图、64 人学生表及工程记忆模板。
- 实际查看 Notion 官方 Projects 产品截图，以浅色侧栏、细线表格、低饱和课程卡组织桌面 UI。
- 预置学期课表和不连续周次，实践课缺少具体时间则放入备忘。初始开学日期取截图 2026-09-07，并可修改。
- 实现逐人 +1、批量登记、补记、明细调整、撤销恢复、自定义类型、日期与课程筛选、Excel/Markdown 汇总。
- 实现新名单预览及独立工作台，完整 JSON 校验恢复和历史快照副本。
- 桌面 SQLite 事务保存到独立数据目录，浏览器 IndexedDB，持久化成功才更新计数；保留版本冲突检查。
- 原名单、截图、个人发行物、SQLite 及备份均被 Git 忽略；个人构建包含名单，远程源码不包含。

## 文件变更

主要目录：src/、src-tauri/、tests/、scripts/、docs/、wiki_memory/。根 README.md 与 AGENTS.md 记录开发、发布、数据保护、记忆与提交规范。

发行位置：dist/GuiLu-latest/归录.exe、dist/GuiLu-latest.zip。开发预览固定 15473，避免本机项目端口冲突。打包脚本兼容 Windows PowerShell，使用 .NET 压缩与哈希，不依赖缺失的模块。

## 测试与验证

- TypeScript / Vite 生产构建通过。
- 11 项业务测试、4 组浏览器场景、2 项 Rust 数据测试通过。
- 桌面隔离目录登记、刷新、退出重启后记录与版本持久化通过。
- Windows 原生保存对话框输出完整 JSON，并读回核对记录通过。
- 1440 和 1100 像素窗口截图检查通过，无横向页面溢出。
- 交付目录中的 EXE 启动和正常退出通过，首次数据为 64 人、0 条考勤、版本 1，无测试记录。
- ZIP 与解压版 EXE 的 SHA-256 一致；发行版未开启调试端口。
