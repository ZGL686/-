# Ludian 0.3.0 验收记录

日期：2026-09-20。自动检查与本机实测完成；实际屏幕上的字体观感和交互偏好仍由用户验收。

## 白屏原因与修复

原按钮是“收起侧栏”。旧布局把首列设为 0，同时隐藏侧栏；CSS Grid 自动排列把主内容移入了宽度为 0 的首列。1440px 视口下实测主内容由 1208px 变为 0px，JavaScript 没有报错，因此仅检查异常日志不能发现这个问题。

现在使用明确的 sidebar / main 网格区域，主内容始终属于 main，展开入口固定在顶栏；折叠后侧栏不可聚焦。新增回归在六个页面和三种宽度中检查实际尺寸及反复收展。页面级与根级错误边界另提供重试 / 返回 / 重新载入，保留已有数据。

## 界面、字体与公共模块

- 左上角只保留班级、学期和黑白 L 标识，点击统一切换或新建工作台；移除重复品牌标题与下方工作台列表。
- 四种字体：默认柔和圆体、手写文楷、原简洁黑体、系统字体；三档字号、减少动效、即时预览和恢复默认。三款内置字体离线完整提供，不按真实名单生成字符子集。
- 按钮悬停 / 按下 / 焦点、图标提示、菜单与弹窗、侧面抽屉、看板及列拖动落点统一反馈；遵循系统或手动减少动态效果。
- AppShell、导航元信息、PreferencesProvider、公共 UI 与数据库 / 设置特性分层；删除旧大型重复入口，考勤编辑器共用。样式按设计变量、基础、外壳、业务、浮层与交互拆分。
- 原应用标识、SQLite / IndexedDB 名称、备份身份、schema 2、事务及乐观版本检查保持兼容。业务写入失败在顶栏持续提示，只有成功后显示已保存。

## 桌面与视觉实测

- 在独立 SQLite 与独立 WebView2 目录，用两名虚构学生的 schema 1 快照进行验收。
- 原考勤保留；新增后为两条，4 个历史快照，最初 payload 完全未变。自定义属性、画廊视图及外观偏好退出重启后保留。
- 原生 Windows 保存对话框导出 JSON 并读回通过；通过 WebView 平台字体接口分别确认圆体、文楷、黑体实际加载。
- 1100×760、1440×1000、2048×1152 / DPR 1.25 检查主要页面、详情、弹窗与四字体，未发现页面级横向溢出或 JS 错误；人工查看截图。截图使用虚构数据，仅保存在本机忽略目录。
- 首轮测试发现 QA 配置使用绝对 dataDirectory 被 Tauri 忽略，导致测试外观缓存沿用默认 WebView 目录；考勤始终使用独立目录。已改用运行时环境覆盖并校验子进程实际路径，隔离重跑通过；仅清除了与测试值完全匹配的新增外观缓存键，没有清空浏览器缓存或真实数据库。
- 最终解压版 Ludian.exe 在另一独立双目录启动并正常退出，使用虚构旧快照，原 payload 不变；实际 WebView 参数没有调试端口。
