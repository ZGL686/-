## 关键覆盖

数据库测试验证了看板拖动改变分组值，表格与画廊同步；行内和侧面编辑、关联跳转、考勤改属 / 撤销后汇总重算；自定义数字、日期、多选和复选框；批量编辑；AND/OR 筛选、多级排序、数字与单选排序语义；筛选后列计算；视图复制 / 删除 / 显示列隔离；表头操作和列拖动；备份往返及属性删除清理。

v1 迁移测试使用虚构旧数据，验证旧学生、课程和考勤不变；v2 属性、视图、值在备份及恢复副本后保持独立。类型错误、无效日期、孤立属性值、缺失当前视图会拒绝保存。

桌面验收通过 `npm run test:native` 可重复执行。界面截图和临时数据库在 `.local/` 中，不进入仓库。真实名单只用于个人发行初始化，不用于自动化登记测试。
