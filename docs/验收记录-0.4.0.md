## 数据与桌面隔离

- 数据 schema 升至 3，以保留回收站标记。兼容读取 1 / 2，首次成功保存才写入新版；旧快照不变。旧版应用拒绝新版数据，避免丢弃新字段。
- 应用标识 `cn.guilu.attendance`、SQLite / IndexedDB 身份、备份身份、事务和版本冲突检查不变。完整备份包含回收站，恢复副本保留删除状态并选中使用中的副本。
- 桌面测试创建虚构名单的旧版 SQLite，分别指定全新 `GUILU_DATA_DIR` 与 `WEBVIEW2_USER_DATA_FOLDER`；先校验真实目录，再操作。原始记录、原始快照与自定义属性保留，未读取或修改真实用户数据库。
- 原生验收覆盖：登记保存、三种离线字体、JSON 保存对话框、工作台创建 / 编辑 / 删除、深色窗口标题栏、偏好与回收站重启保留、工作台恢复、减号撤销与恢复，共 11 个快照。
- 功能自动化使用独立 Debug 构建。直接尝试发行 EXE 的 CDP 连接被拒绝，因此不把该次尝试计为功能通过；最终发行 EXE 另做正常启动、实际窗口截图、原 SQLite 内容不变、正常退出及无调试端口检查。生产与 Debug 前端资源哈希一致。
