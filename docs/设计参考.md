# 界面与课表依据

参考日期：2026-09-20。

查看了 [Notion 官方 Projects 页面](https://www.notion.com/product/projects) 及该页的 [Issue Tracking 产品截图](https://images.ctfassets.net/spoqsaf9291f/5kXRXwCLL3fQ3hpRcxPB90/d2b0da73dfc81ff9a5748b07a63dc680/database-container.png)。采用轻量表格、低饱和标签、细线、留白和左对齐标题；归录选择浅灰侧栏及柔和绿色导航重点。

用户的四张移动截图用于确定当前周、日期、周次选择、开学日期和课程详情的语义。桌面版采用侧栏、七日课表和今日安排，较窄窗口隐藏补充侧栏，保留完整周表。

课程依据用户的 Markdown 周课表。三维基础建模在 1–2、4–13 周上课，14–15 周周一切换课程设计；多媒体技术与应用合并第 5–8 节显示。第 16 周课程设计和第 17 周专业见习未给出时段，列入备忘。

开学日期初值为截图中的 2026-09-07，支持随时调整。第 1–8 节作息和第 9 节开始时间来源明确，其余晚间时间作为可编辑初始值标注。

名单用于本地个人版；源表、截图、数据库与个人发行文件不进入远程源码仓库。
