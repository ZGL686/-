## 数据库行为研究与落地

| 官方资料 | 本轮落地 |
| --- | --- |
| [视图、筛选、排序、分组](https://www.notion.com/help/views-filters-and-sorts) | 同一数据的多个保存视图；每个视图独立的条件、排序、显示列、分组；新建、复制、重命名、删除视图 |
| [数据库属性](https://www.notion.com/help/database-properties) | 文本、数字、单选、多选、日期、复选框；行内编辑、属性设置及类型校验 |
| [表格](https://www.notion.com/help/tables) | 属性表头、批量编辑、列重排和列宽、显示列、列计算、标题固定、右侧详情 |
| [看板](https://www.notion.com/help/boards) | 按属性分组，拖动卡片改变可编辑属性；保留空选项组 |
| [画廊](https://www.notion.com/help/galleries) | 自适应卡片网格，以学生资料和选定属性作为内容 |
| [日历](https://www.notion.com/help/calendars) | 以日期属性放置记录，月切换和未设置日期区域 |
| [关联与汇总](https://www.notion.com/help/relations-and-rollups) | 考勤关联学生，双方详情互相跳转；学生异常次数从有效记录重算 |
| [数据库设置](https://www.notion.com/help/customize-your-database) | 区分视图配置与数据库共有属性，配置写入本地工作台并纳入备份 |

实现适配考勤业务：学生和考勤是两个固定数据库，历史课程保存快照，课表调整不重写考勤。学生计数是登记次数，不推导出勤率。自定义跟进状态、备注等独立于考勤。

本轮提供五种视图与六类自定义属性，不包含 Notion 全套公式语言、任意数据库创建 / 自定义关联、时间轴、协作权限和在线自动化。筛选是同级 AND / OR 条件，没有嵌套条件组。现有的汇总页提供业务统计和 Excel/Markdown 导出，数据库视图提供包含自定义属性的 CSV。

## 视觉规则与字体

- 白色主区域 `#ffffff`，浅灰侧栏 `#f7f7f5`，深灰文字 `#37352f`，细线 `#e9e9e7`。蓝色 `#2383e2` 主要用于新建、保存及当前日期。彩色仅保留在分类标签和课程识别线。
- 侧栏缩减成紧凑导航；取消绿色品牌块、个人身份装饰、页脚口号和大块外边距。数据库使用全宽内容区域、视图标签及一行工具栏；课表改为完整宽度，今日安排与备忘放到下方。
- 主体文字 14px，辅助信息通常 12–13px。避免原来的 8–10px 课表正文，以及 450/550/650 等不明确的系统字体字重。没有用页面缩放或文本 transform 补偿尺寸。
- 用 CDP 检查后确认初版实际回退到 Microsoft YaHei UI，并非宋体。Windows 注册表显示 ClearType 已启用，未擅自改变系统设置。小字号、字重和渲染缩放都会影响边缘观感，无法仅凭用户截图确定唯一原因。
- 内置官方 [Noto Sans SC](https://github.com/google/fonts/tree/main/ofl/notosanssc) 可变字体，保持本地离线加载；保留全部字符映射，没有按名单生成字形子集。通过浏览器和桌面 WebView 的平台字体接口确认实际使用自定义字体。许可见 `public/fonts/OFL.txt`。

## 课表和名单依据

继续沿用用户 Markdown 课表与最初的四张课表截图。三维基础建模在 1–2、4–13 周上课，14–15 周周一切换课程设计；多媒体技术与应用合并第 5–8 节。第 16 周课程设计和第 17 周专业见习没有具体时段，留在备忘。

开学日期初值为 2026-09-07，可随时更改。部分晚间作息仍为可编辑初始值。真实学生名单、个人截图、数据库和发行文件仅留本机，不进入远程仓库。
